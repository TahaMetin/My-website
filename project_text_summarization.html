Text Summarization

Made with Python and PyQt5 · Transforms sentences in a given document into a graph structure · Creates a summary with an algorithm using the nodes in the graph

Project Description

This project aims to develop a desktop application and perform text summarization operations. In line with the desired objectives, it is aimed to convert sentences in a document into a graph structure and visualize them graphically. The goal is to extract text summaries using this structure.
