Java 21 migration for banking microservices

Moving multiple production microservices from Java 8 and 17 to Java 21, together with Spring Boot upgrades and Maven/Gradle dependency updates.

Role
Software Engineer, contributor
Stack
Java 8 / 17 → 21, Spring Boot, Maven, Gradle
Delivery
ScoreTFS CI/CD, XL Release

Context

The services behind several banking and financial products were running on a mix of Java 8 and Java 17. Older runtimes meant older framework versions, ageing dependencies and diverging build setups across teams. The platform team started infrastructure work to bring services onto Java 21.

My role

I contributed to the migration infrastructure work and migrated multiple microservices myself, from the build files through to a successful pipeline run.

What I did

  • Raised the Java version of each service to 21 and upgraded Spring Boot to a compatible release.
  • Updated Maven and Gradle dependencies, replacing or bumping libraries that did not support the new runtime.
  • Fixed the compile errors and failing tests the upgrade surfaced, keeping the services' behaviour unchanged.
  • Verified each service through the CI/CD pipeline before handing it to release orchestration in XL Release.

Outcome

The migrated services run on a current, long-term-supported Java version with up-to-date framework and dependency versions, which makes future upgrades and security patching simpler.

Details are generalised to respect client confidentiality.
