Customer data migration with DataStage

IBM DataStage ETL jobs, run with batch job scheduling, that migrate customer data across enterprise databases into Oracle.

Role
Software Engineer
Stack
IBM DataStage, Oracle Database, SQL, PL/SQL
Type
ETL, batch jobs, data migration
ContextMy roleWhat I didOutcome

Context

Customer data held across several enterprise databases had to be brought into Oracle so that the services built on top of it could use it.

Enterprise databases →DataStage: extract · transform · load →Oracle DB

My role

I built the DataStage ETL jobs for the migration and set them up to run as scheduled batch jobs.

What I did

  • Built jobs that extract customer records from the source enterprise databases.
  • Transformed the data to fit the target Oracle schema.
  • Loaded it into Oracle and checked the results with SQL.
  • Configured batch job scheduling so the migration runs as scheduled batches.

Outcome

Customer data became available in Oracle for the services that depend on it.

Details are generalised to respect client confidentiality. No customer data is shown.
