Case study · Softtech

Customer data migration with DataStage

ETL jobs in IBM DataStage that move customer data from bank databases into Softtech's Oracle databases.

Role
Software Engineer
Stack
IBM DataStage, Oracle Database, SQL
Type
ETL, data migration

Context

Customer data held in the bank's own databases had to be brought into Softtech's Oracle databases so the services built on top of them could use it.

Bank databases→ DataStage: extract · transform · load→ Softtech Oracle DB

My role

I developed the DataStage ETL jobs for the migration.

What I did

  • Built jobs that extract customer records from the source bank databases.
  • Transformed the data to fit the target Oracle schema.
  • Loaded it into the Softtech Oracle databases and checked the results with SQL.

Outcome

Customer data became available in the target Oracle databases for the services that depend on it.

Details are generalised to respect client confidentiality. No customer data is shown.
