Cover letter

I'm a backend engineer. For two years at Softtech I developed and maintained Java and Spring Boot microservices for banking products, including commercial loan decisioning.

I built webMethods flow services on the ESB that route data from new services to Java backends, where it is persisted in Oracle or processed by the decision engine for commercial loan credit scoring. I also contributed to the Java 21 migration, built IBM DataStage ETL jobs to migrate customer data, and wrote unit tests with JUnit 5 and Mockito to raise test coverage.

On the production side, I traced issues through Log4j2 logs on OpenShift, delivered bug fixes and hotfixes, resolved incident records within SLA and supported releases through Azure DevOps and Digital.ai Release.

I'm now looking for backend roles in fintech and beyond. The case files below show this work in more detail.
