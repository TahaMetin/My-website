Smurfs Maze Game

Made with java and javaFX · School project aiming to use dijksta algorithm

Project Description

A Smurfs-themed maze game created using Java and JavaFX. In the maze, there are 2 enemies chasing you, and your goal is to collect as many points as possible without getting caught by them and try to exit the maze.

Features and Systems Used

  • Dijkstra algorithm
  • java
  • javaFX
  • OOP prenciples and clean code
  • Enemy AI and health system
