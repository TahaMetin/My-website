Text Merge

Made with Java · Text-merging app · Aims to develop new algorithms for merging multiple texts

Project description

New algorithms and a visual interface for merging texts taken from books, magazines and similar sources. The project finds similarities and frequencies between sentences and words, decides how to merge the texts, and combines sentences and words character by character based on that data. The interface has at least two text inputs, a merge button and a save button that stores the texts in .json format. It is written in Java and uses MongoDB as a NoSQL database, where the texts are stored as documents for listing and saving.
